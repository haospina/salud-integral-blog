# ✍️ Guías de Publicación

Aquí se presentan las pautas básicas para publicar en el blog:

- **Formato de archivos:** se recomienda usar Markdown (`.md`) para mantener la compatibilidad con Jekyll.  
- **Estructura mínima:** título, introducción, desarrollo y conclusiones.  
- **Referencias:** incluir bibliografía siguiendo normas Vancouver o APA.  
- **Revisión:** cada publicación debe ser revisada por un tutor antes de ser subida.  

Estas guías aseguran que los trabajos mantengan un estándar académico y sean fáciles de consultar.
